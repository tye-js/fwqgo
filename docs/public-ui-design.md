# FWQGO 公开前台设计

方向：清爽、专业的科技媒体。使用真实文章、知识条目与服务器库存组织内容；通过排版、阅读节奏和选购路径增加信息价值。

## 视觉规范

| 项目     | 规范                                                                                  |
| -------- | ------------------------------------------------------------------------------------- |
| 主色     | 蓝色 `hsl(220 83% 49%)`，用于链接、主要操作和少量强调                                 |
| 背景     | 浅蓝灰页面底色，白色内容面板                                                          |
| 排版     | 复用 Inter / Outfit，中文使用系统字体回退；标题层级清晰，长文行距约 1.95              |
| 栅格     | 内容最大宽度 1248px，响应式边距 16–32px                                               |
| 卡片     | 16px 圆角、细边框、轻阴影；重点文章、普通列表与紧凑卡片共用组件                       |
| 图片     | 保留真实封面；默认图或加载失败时展示轻量服务器 SVG 插画                               |
| 交互     | 主要触控区至少 44px；桌面展开导航从 xl 开始，平板使用抽屉；保留键盘焦点与减少动画设置 |
| 样式隔离 | `src/styles/public.css` 仅由 Web 根布局导入，并限定在 `html.public-site` 下           |

## 页面组织

| 页面                 | 新结构                                                                                                  |
| -------------------- | ------------------------------------------------------------------------------------------------------- |
| 中英文首页           | 检索与库存入口、新近发布的重点文章、四条选购路径、文章列表、优惠码与热门阅读、地区/商家目录、知识库更新 |
| 文章归档、分类与标签 | 清晰的主题介绍、真实文章数量、统一文章卡片、相关套餐和阅读侧栏                                          |
| 文章详情             | 白色阅读面板、完整摘要、更清晰的正文/引用/表格样式，保留目录、分享、语言关系和关联内容                  |
| 知识库               | 独立搜索区、分类速查、定义/要点/提示分层的知识卡片                                                      |
| 服务器库存与专题     | 更清晰的入口说明、白色筛选与结果区域，继续提供价格、库存、配置和购买链接                                |
| 配置与线路工具       | 与正文页面统一的标题区和表单面板，原计算和筛选规则保持兼容                                              |
| 搜索与 404           | 可直接操作的搜索表单、清晰结果分组，以及知识库/线路/配置/库存入口                                       |

## 内容与兼容

- 中英文首页共享展示组件，但分别读取对应语言的文章、知识库与推广位。
- 收录量、更新时间、优惠码、商家与地区均来自现有数据。无数据时提供明确的空状态和可用入口。
- 不恢复已经删除的首页“最新精选套餐”列表；服务器对比通过目录和库存入口承接。
- 保留文章、分类和标签 URL、分页、购买链接及公开索引规则；非公开可索引标签继续只展示文本。
- 保留 Cache Components/ISR、初始 HTML 正文、文章元信息和 RSC 缓存隔离。首页新增知识库内容后同时订阅知识库缓存标签。
- 本轮不修改 CMS 工作流，不增加 UI 框架、图片服务或第三方字体依赖。

## 验证

- `bun run verify:public-ui` 使用服务端真实组件渲染，检查中英文链接、独立文章目标、真实计数的展示边界、空状态、标签索引规则和图片加载优先级。
- Bun 1.4.2 下 `bun run check` 已通过，包括移动端结构、缓存边界、SEO、lint、类型、520 项既有本地测试及新增的两项服务端渲染回归。
- Web/CMS 双应用构建与 `smoke:built` 已通过，构建产物中已确认包含新的前台样式。验证使用本地测试环境，没有操作生产数据。
- 已计算浅色与深色的正文、辅助文字、主要操作和链接对比度，均达到 WCAG AA；最低为浅色辅助文字的 5.36:1。
- 真实浏览器预览和静态预览文件生成均被自动审批服务拦截，审核接口返回 404。未生成可交付的页面截图或静态预览，真实视口、点击和键盘交互仍待验收。
- 本轮未提交、推送或部署。
