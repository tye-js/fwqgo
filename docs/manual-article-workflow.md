# 人工文章生产链路

文章生产台支持网址、文本、邮件、文件和来源站批量采集。后台只读取、清洗素材并处理现有返利链接规则，不调用正文改写、英文翻译或文章 SEO 模型，也不要求启用改写配置。

1. 采集完成后，任务进入“需人工处理”。任务详情保留完整清洗原文。
2. 在任务详情人工输入正文、标题、slug、摘要、关键词和标签。中文任务可主动将采集正文填入编辑器，再自行修改；英文任务以中文文章为参考。
3. 保存时在同一事务内创建草稿、关联任务并记录人工完成状态。版本变化或重复提交会被拒绝，已有草稿使用文章编辑页维护。
4. 草稿立即使用 `/img/placeholders/fwq-placeholder.png`。保存操作不调用 AI、不创建生图任务，也不依赖生图配置。
5. 需要 AI 封面时，在文章编辑页手动点击“生成封面图”，确认视觉简报后才排队。后台生成成功后替换默认图并刷新图片引用和公开缓存；生成失败时保留当前封面。从默认图启动的任务不会覆盖生成期间人工更换的封面。

文章列表的英文和 SEO 操作创建人工编辑任务。旧的排队、失败或中断任务重试时也采用人工流程。历史模型调用及候选内容继续可查，不再用于自动覆盖文章。

本改动无需数据库结构迁移。分类、标签等独立功能的配置和历史文章数据保持兼容。
