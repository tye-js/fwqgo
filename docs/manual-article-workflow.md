# 文章采集与草稿编辑

文章生产流程收敛为：**读取素材 → 清洗正文 → 替换返利链接 → 保存草稿**。

## 采集与保存

- URL、文本、邮件和文本文件共用同一入稿流程，不调用正文改写、翻译或文章 SEO 模型，也不要求可用的文本模型配置。
- 清洗后的完整来源快照单独保存。返利链接替换后的正文作为 Markdown 保存到草稿，表格中的各套餐购买链接完整保留，不按历史 AI token 限制截断。
- 每篇文章只读取一次返利商家配置。参数模式只替换指定参数；`affParam=href` 仍替换成数据库配置的整条地址。
- 使用来源标题和已有摘要作为初值，草稿 slug 带任务 ID 以区分不同采集任务；关键词、标签及最终 SEO 由编辑补充。缺少摘要或标签不会阻止保存草稿。
- 草稿、任务完成状态、素材完成状态和保存步骤在同一事务中提交，并核对任务租约。保存失败会回滚；重复执行不覆盖已经编辑或发布的文章。
- 新采集任务直接到 `succeeded`，不再停在 `manual_required`。旧的待人工处理任务可点击重试，优先使用完整来源快照入稿，无需重新访问已下线的来源。

## 编辑与复制

草稿箱进入文章编辑页后，在正文工具栏点击“复制全文”，复制的是编辑框内的全部 Markdown，包括尚未保存的修改、表格、列表和链接。剪贴板不可用时会选中全文并提示手动复制，不会误报成功。

正文和 SEO 统一在草稿中编辑。保存未发布草稿允许摘要与标签尚未完成；从正文编辑页发布时继续校验正文、摘要和标签。

英文版本保持原有流程：保留单篇和批量“填写英文稿”入口，创建英文编辑任务，保留中文来源参考，人工输入英文正文与 SEO 后原子保存为独立英文草稿。英文任务可以重试，已有英文文章保留并提供编辑入口，不覆盖中文原文或已有译文。仅移除独立 SEO 编辑队列，SEO 在文章编辑页维护。

## 封面与历史兼容

新草稿立即使用 `/img/placeholders/fwq-placeholder.png`。保存不查询图片配置、不创建生图任务。只有手动点击生成封面才启动后台任务，成功后替换默认/空封面；保留生成期间手工选择的封面。

中文采集的人工入稿等待表单、独立 SEO 派生任务、重复生产链路、模型 token 面板及 AI 质量规划步骤已退出采集流程。英文版本的人工表单与派生任务保留。任务表字段和历史模型调用记录保持可读，任务详情将旧步骤收在历史记录中。未删除生产数据，也不需要数据库迁移。
